Política de privacidad de Canal Shorts Uploader

Última actualización: 25 de noviembre de 2026.

Qué datos usa la aplicación

Con el permiso del propietario del canal, la aplicación usa la API de datos de YouTube para:

  • subir vídeos al canal del propietario (permiso youtube.upload);
  • leer los títulos y fechas de los vídeos ya publicados en ese canal (permiso youtube.readonly).

Qué no hace

No recoge datos de otros usuarios ni de espectadores. No vende, comparte ni transfiere datos a terceros. No usa los datos para publicidad. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Almacenamiento

El token de acceso se guarda solo como credencial privada del propietario en su entorno de ejecución y nunca se publica. Se puede revocar en cualquier momento desde myaccount.google.com/permissions.

Contacto

A través del canal de YouTube.
